# LR Rekordable

ListenRadio（リスラジ）の番組を予約して自動で録音する、Mac のアプリです。

> **ご注意** LR Rekordable は ListenRadio の公式アプリではありません。録音した番組は、個人で楽しむ範囲（私的利用）でお使いください。再配布やインターネットへの公開はできません。

## できること
- 全国のコミュニティ FM などの**番組表**を見て、番組を**予約**（この回だけ／毎週）。来週の分も、推定の番組表から予約できます
- 予約の時刻になると**自動で録音**し、AAC（.m4a）のファイルで保存します。ミュージック・QuickTime Player・iPhone などでそのまま再生できます
- 録音中、**音はスピーカーやイヤホンに出ません**（作業中や夜間でも静か）
- いま放送中の番組を**放送途中から録音**したり、その場で**聴いたり**できます
- 複数の局の番組を**同時に録音**できます
- 設定で有効にすると、**スリープ中の Mac を予約の前に起こして**録音します（ふたを閉じたままでもかまいません）
- 条件で番組を集める**スマート番組表**、録音の**続きから再生**、**メニューバー**からの操作など

## 動作環境
| | |
|---|---|
| OS | macOS 14.4 以降（Apple シリコン・Intel） |
| ネット接続 | 必要（番組表の取得と、録音・試聴に使います） |
| 表示の言語 | 日本語 |
| 録音形式 | AAC 128kbps ステレオ（.m4a）。1 時間でおよそ 60MB |

## 入れ方
1. [Releases](https://github.com/xmotordrive-cmd/lr-rekordable/releases/latest) から `LR Rekordable <版>.dmg` をダウンロードします
2. DMG を開き、**LR Rekordable** を「アプリケーション」フォルダにドラッグします
3. 「アプリケーション」フォルダから起動します（Apple の公証を受けているので、そのまま開けます）
4. 初めて起動すると「はじめの設定」の案内が開きます。録音の完了をお知らせする**通知**と、Mac を再起動したあとも録音できるように**ログイン時に開く**、必要なら**スリープ中の予約録音**を設定してください

使い方は、アプリのメニューの **ヘルプ ＞ LR Rekordable ヘルプ**（説明書）で見られます。PDF の説明書もアプリに入っています（**ヘルプ ＞ 説明書（PDF）を開く**）。

## 新しい版にするとき
新しい版が出ると、アプリが通知でお知らせします（1 日に 1 回確かめます。設定でオフにできます）。メニューの **LR Rekordable ＞ アップデートを確認…** でいつでも確かめられます。

入れ替えるときは、録音中でないことを確かめてからアプリを終了し、新しい版を「アプリケーション」フォルダに入れて置き換えてください。予約・設定・録音はそのまま引き継ぎます。

## 知っておいてほしいこと
- **アプリが起動していないと録音できません。** ウインドウは閉じてもかまいません。設定の一般の「ログイン時に開く」をオンにすると、Mac を再起動したあとも自動で起動します。いつも起動しておくなら、設定で「メニューバーだけに表示」にすると Dock がすっきりします
- **スリープ中の予約録音**を有効にしないと、Mac がスリープしているあいだは録音できません。システム終了（電源オフ）している Mac は起こせません
- 録音は ListenRadio 公式サイトのプレーヤーを使っています。公式サイトの作りが変わると、録音や番組表の取得ができなくなることがあります。そのおそれがあるときは、アプリが自動で気づいて警告を出します
- 同時に録音できる数は、Mac の CPU とメモリから決まります（設定に表示されます）

## スリープ中の予約録音のしくみ
有効にするとき、管理者パスワードを 1 回だけ入力します。このとき macOS に、このユーザーが「Mac を起こす予定を入れる・取り消す」と「スリープしない／元に戻す」の操作（`pmset`）**だけ**をパスワードなしで実行できる規則（`/etc/sudoers.d/listenradiorecorder`）を登録します。ほかの操作には使えません。設定の「無効にする…」で、いつでも取り除けます。

## プライバシー
- 使う人の情報や、使い方の記録をどこかへ送ることはありません
- 通信するのは、番組表・録音・試聴のための **ListenRadio の公式サイト**（公式サイトが読み込む広告などを含みます）と、新しい版を確かめるための **GitHub** だけです。GitHub にはアプリの名前と版だけを送ります
- 予約・設定・ログ・録音は、すべてこの Mac の中に保存します

## アプリを削除するとき
設定（⌘,）の **管理** のタブにある **アンインストール…** を押してください。確認のあと、予約・設定・ログ・キャッシュと、スリープ中の予約録音の設定を取り除き、アプリをゴミ箱に入れて終了します。**録音ファイルは残します。**

Finder でゴミ箱に入れるだけでは、スリープ中の予約録音の規則が残ります。先にアプリを消してしまったときは、ターミナルで次を実行してください（管理者のパスワードを聞かれます）。Mac を起こす予定は、最長 4 週間で自然に消えます。

```
sudo rm -f /etc/sudoers.d/listenradiorecorder
sudo pmset -a disablesleep 0
```
